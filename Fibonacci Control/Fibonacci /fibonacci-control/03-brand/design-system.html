01 Философия системы

Три правила, из которых выведено всё

Выводимость

Кегль, отступы, сетка — всё из ряда Фибоначчи. Нет «магических чисел»: если значение не из ряда, оно не появляется в коде. Отступы = Фибоначчи × 4px.

Латунь = действие

Акцентный цвет ≤5% площади и означает ровно одно — «здесь решает человек». Один экран — одно главное действие в латуни. Никогда не статус.

Dark-first

Тёмная база — состояние по умолчанию, а не тема. Латунь и данные читаются на Void. Это же экономит глаза оператору CRM, который сидит в системе весь день.

06 Motion

Кинетическая типографика

Тот самый приём из референса: заголовок «строится» по словам при скролле. Стек 2026 — GSAP + ScrollTrigger + SplitText. Наведите на блок, чтобы проиграть:

Порядок — это не случайность

▸ навести для проигрывания

typescript
// Kinetic reveal — текст «строится» по словам при скролле.
// Именно этот приём даёт эффект дублированных строк как в референсе.
// Стек 2026: GSAP + ScrollTrigger + SplitText.
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
import { SplitText } from 'gsap/SplitText'
gsap.registerPlugin(ScrollTrigger, SplitText)

// уважаем reduced-motion — обязательно
const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches

document.querySelectorAll('[data-reveal]').forEach((el) => {
  if (reduce) return                       // при reduce просто показываем
  const split = new SplitText(el, { type: 'words' })
  gsap.from(split.words, {
    yPercent: 120, opacity: 0, duration: 0.8, ease: 'power4.out',
    stagger: 0.06,
    scrollTrigger: { trigger: el, start: 'top 82%', once: true },
  })
})
Длительности
fast.3s
base.6s
slow.8s
Ease

cubic-bezier(.22,1,.36,1)
Один ease на всё. Резкий старт, мягкое торможение — «инженерное» ощущение.

Правило

Анимируем только transform и opacity (compositor-thread, 60fps). Никогда width/height/left. prefers-reduced-motion — обязательно.

08 Готовый код

Токены — вставить в проект

Первый блок — CSS-переменные (любой стек). Второй — расширение Tailwind, если используешь его. Оба выведены из одной шкалы Фибоначчи.

:root{
  /* — surface (тёмная база, dark-first) — */
  --fc-void:#070A10;      /* фон страницы          */

  --fc-surface:#121A26;   /* приподнятые панели    */
  --fc-line:#1E2836;      /* границы, разделители  */

  /* — текст — */
  --fc-fg:#FBFBFC;        /* основной              */
  --fc-dim:#98A3B4;       /* вторичный             */
  --fc-slate:#6B7688;     /* третичный, подписи    */

  /* — акцент (латунь, ≤5% площади) — */
  --fc-aurum:#D2A24C;
  --fc-aurum-lit:#EFC97E; /* hover, свечение       */
  --fc-aurum-deep:#9A6F1E;/* текст-латунь на светлом (AA 4.6:1) */

  /* — типографика — */

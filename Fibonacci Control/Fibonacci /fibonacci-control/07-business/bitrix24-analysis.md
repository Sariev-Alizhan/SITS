## 3. ИИ CoPilot — ключевая цель [CONFIRMED helpdesk]
- **Это ассистент-генерация/суммаризация, НЕ автономный агент с инструментами.** Делает: черновики текстов/тон, чек-листы, саммари, Q&A с «ролями», **транскрипт звонка → саммари → автозаполнение полей сделки (единственное автономное write-действие)**, речевая аналитика по скриптам, описания товаров, генерация сайтов/картинок.
- Автономность — только через отдельный слой: **MCP-сервер (осень 2025)** позволяет ВНЕШНЕЙ модели (ChatGPT/Claude) делать действия — но это плумбинг, не «из коробки». «Настраиваемые ИИ-агенты» в Automation Studio — [MKT], реальная автономность неясна.
- **Модели:** глобально **gpt-3.5-turbo** [CONFIRMED] (устарело для 2025–2026); РФ — YandexGPT/GigaChat/BitrixGPT.
- **Жёсткий лимит:** 100–400 «ИИ-запросов»/мес на ВСЮ компанию (Free/Basic/Standard 100, Prof 200, Ent 400). Докупка +1000 ≈ 9 900 ₽/мес. **Скоринг лидов ИИ — [MKT/UNVERIFIED]**, в доках нет.

## 4. Мобилка
- Возможности урезаны vs веб (нет личных Scrum-спринтов, ограничены кастомполя/аналитика/автоматизация).
- Рейтинги: App Store US 4.4 (~1,1k), RuStore 4.5 (700k+ установок), Google Play ~4.2 (не подтверждён прямым fetch).
- **Жалобы 2024–2026:** краши/фризы в дороге, **«сообщения приходят с задержкой в дни»**, ошибки логина, медленный чат/поиск, задержка синка на слабом сигнале. **Push — боль:** «Intelligent mode» глушит push телефона когда открыт десктоп; плюс спам уведомлений. Offline только частичный.

## 8. Мобильная стратегия «как приложение»
- **⚠️ Поправка:** КЗ НЕ Android-доминантный для нашего покупателя. Statcounter 2026: Android ~53,8% / iOS ~46,2%, **Apple — крупнейший вендор ~46%** (урбан/платёжеспособные = наши ЛПР). iOS игнорировать нельзя.
- **PWA даёт ~90% ценности нативки при −60–70% стоимости** — CRM/дашборды это прототип «PWA достаточно». Один код, мгновенные обновления.
- **iOS — где трение:** нет авто-подсказки установки (вручную «на экран Домой»); web-push только после установки (iOS 16.4+) и «капризный».
- **TWA** (Bubblewrap/PWABuilder) → тот же PWA в Google Play дёшево (Android-only, Apple тонкие обёртки отклоняет).
- **Capacitor** — обёртка под ОБА стора из одного кода, даёт **надёжный нативный APNs push на iPhone** — самый ценный апгрейд при ~46% iOS.
- **Рекомендация:** Фаза 1 — нормальный PWA (основной мобильный опыт) → Фаза 2 — TWA в Play Store (почти без усилий, «значок» доверия) → Фаза 3 — Capacitor в App Store когда нужен надёжный iOS-push. **Полную нативку/React Native — не надо** (CRM не оправдывает второй кодбейс).

## 9. Самые острые точки против Битрикса (для лендинга и продаж)
1. Настоящий ИИ-агент, делающий действия, vs ассистент-генерация + один автозаполнитель.
2. Frontier-модель (Claude) vs их gpt-3.5-turbo (глобал).
3. Щедрый ИИ vs 100–400 запросов/мес на компанию.
4. **WhatsApp с личного номера без платы за диалог, встроен** — бьёт по их главному повторяющемуся расходу (WABA + провайдер).
5. Простота vs обучение 2–4 недели.
6. Быстрая мобилка + надёжный push vs задержка сообщений «в дни».
7. Мультикомпания с изоляцией на уровне БД (их облако — один портал).
8. Тендеры госзакупок КЗ в CRM (у них нет).
9. GPS-автопарк в CRM (у них — только сторонние приложения Маркета +20%).
10. Камеры-в-CRM (склад/точка/объект).
11. Kaspi-first, рус/каз, местные платежи/курьеры.
12. Прозрачная цена без лок-ина + выгрузка в один клик vs рост цен и болезненная миграция.

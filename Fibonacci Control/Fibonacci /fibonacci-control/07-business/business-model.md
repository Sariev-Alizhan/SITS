## 1. Стратегия одной фразой

> **Дешевле Битрикса на входе, дороже по ценности, невозможно догнать по ИИ и WhatsApp.**

Заходим ценой и простотой (Битрикс сложный и на старте уже платный за важное), удерживаем ИИ-сотрудником и WhatsApp-без-доплат, растём вверх по мере того, как клиент получает результат (land-and-expand).

## 4. Воронка продаж = наш продукт в действии (главная фишка)

Мы продаём CRM с WhatsApp-ботом — значит **воронка должна работать на нашем же продукте.** Это и продажа, и живое доказательство.

```
   Реклама (Instagram/таргет) + история бренда
                 │
                 ▼
   ЛЕНДИНГ fibonacci  ──►  кнопка «Оставить заявку»
                 │
                 ▼
   ФОРМА-ЗАЯВКА (клиент описывает свой бизнес):
     • имя, компания, сфера
     • сколько сотрудников / отделов
     • главная боль (заявки теряются? КП долго? нет прогноза?)
     • какие каналы (WhatsApp / Instagram / звонки)
     • контакт (телефон/WhatsApp)
                 │
        ┌────────┴─────────┐
        ▼                  ▼
   Приходит НАМ        НАШ WhatsApp-бот
   в Telegram          сразу пишет клиенту:
   (лид в нашей CRM)   квалифицирует, отвечает,
        │              зовёт на демо, греет
        ▼                  │
   Менеджер Fibonacci ◄────┘
   закрывает: демо → внедрение → подписка
```

**Почему это сильно:**
- Клиент на себе видит, как работает наш ночной/мгновенный WhatsApp-бот — **это и есть демо ещё до демо.** «Вам ответил наш же бот. Хотите такого себе?»
- Заявка = лид в нашей собственной Fibonacci Control. Мы едим свою еду (dogfooding) — лучшая реклама.
- Форма-заявка собирает **ровно те поля, что нужны для разворачивания инстанса** (сфера, юниты, модули, каналы) — то есть это одновременно **онбординг-анкета** (см. раздел 5).

**Что построить:** на уже задеплоенном лендинге добавить секцию-форму (лид → Telegram-бот нам + запись в БД), и подключить наш wa-bot на номер Fibonacci для автоответа заявителю. Обе части у нас уже есть в продукте — нужно только связать.

## 5. Онбординг клиента (от заявки до живого инстанса)

Клиент-бизнесмен **описывает, как устроен его бизнес** — а мы превращаем это в развёрнутую CRM. Анкета онбординга = блок «ДАННЫЕ КЛИЕНТА» из `MASTER_PROMPT.md`:

1. **Заявка/анкета** — название бренда CRM, сфера, юниты (юрлица/бренды), нужные модули, каналы, каталог (CSV / ссылки на сайты поставщиков / вручную), домен.
2. **Разворачивание** — по `MASTER_PROMPT.md`: копия шаблона → ребрендинг → юниты → ИИ под сферу → включение модулей → Supabase + деплой на Vercel. Голый брендированный инстанс — за один сеанс.
3. **Наполнение** — каталог (импорт/скрейп), первый админ, сотрудники по ролям.
4. **Интеграции** — WhatsApp-мост (QR), Meta, 1С, камеры — по тарифу, отдельными сессиями.
5. **Приёмка** — смоук-тесты + ручная проверка (Жан отвечает, КП собирается, изоляция юнитов).
6. **Передача** — URL, логин, чек-лист «что включено», апсейл-предложения из невключённых модулей.

Каждый клиент — **свой Supabase-проект + свой Vercel-деплой** (данные физически изолированы; проще и безопаснее мультитенантности, и это же — аргумент против лок-ина Битрикса).

## 6. Юнит-экономика (на один инстанс)

**Себестоимость/мес:** Supabase Pro ~$25 + Vercel $0–20 + Anthropic (ИИ) ~$5–30 + прочее ≈ **$35–80/мес** (~19 000–43 000 ₸).

**Выручка/мес:** тариф Бизнес 49 000 ₸ → **маржа ~55–75%** даже на среднем тарифе, плюс разовое внедрение 150–400к ₸ окупает привлечение сразу.

**Рычаги маржи:** prompt-caching и effort-режимы ИИ (уже в коде) режут расходы на Claude; общий демо-стенд один на всех (не платим за демо каждого лида); скрейперы каталога переиспользуются между клиентами одной сферы.

**Ключевая метрика для масштаба:** время «заявка → живой инстанс». Чем ближе к «один сеанс», тем выше пропускная способность без роста команды. Сюда же — библиотека готовых пресетов по сферам (стройматериалы / мебель / автозапчасти).

## 8. Как остаёмся лучше — принцип обновлений

Не «догоняем Битрикс по галочкам». **Углубляем то, что они структурно не могут.**

- **ИИ-first во всём:** каждый новый модуль сначала спрашивает «что здесь сделает Жан сам?». Битрикс лимитирует ИИ по запросам — мы делаем его ядром.
- **Ритм релизов:** каждый месяц — одна фича, которой у Битрикса нет или которую он берёт за доплату (раздел «Что нового» в CRM уже есть). Пример-очередь: форма-заявка с ботом → нативный мобильный push (Capacitor) → пресеты сфер для мгновенного онбординга → голосовой ИИ по звонкам → углубление тендерного модуля.
- **Слушаем эксплуатацию:** продукт вырос из реального бизнеса — так и держим. Фичи из боли живых пользователей, не из маркетинга.
- **Прозрачность как оружие:** на фоне роста цен и лок-ина Битрикса — честная цена, свой инстанс клиента, выгрузка данных в один клик. Доверие = наш дифференциатор.

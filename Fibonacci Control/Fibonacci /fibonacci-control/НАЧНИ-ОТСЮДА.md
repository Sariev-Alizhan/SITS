## С ЧЕГО НАЧАТЬ

## ЧТО В ПАПКАХ

### `01-landing-project/` — ЛЕНДИНГ (главное)
Готовый Next.js проект. Собирается, запускается, деплоится на Vercel.
Именно его открывает терминал. Внутри свой `README.md` с деталями.

### `02-logo-pack/` — ЛОГОТИП
Все форматы логотипа: SVG (в кривых), PNG (прозрачные и с фоном),
PDF для печати, favicon, аватарки и обложки для соцсетей.
Внутри `ПРОЧТИ-МЕНЯ.md` — какой формат для чего.

### `03-brand/` — ПРАВИЛА
- `brandbook.html` — философия, логотип, цвет, шрифт, голос
- `design-system.html` — токены и компоненты с кодом (эталон для терминала)

Открывай в браузере. Терминал сверяется с `design-system.html`.

### `04-ads/` — РЕКЛАМА ДЛЯ INSTAGRAM
6 готовых креативов (3 угла × фид + сторис) + тексты объявлений
и инструкция по запуску таргета. Всё в `тексты-и-запуск.md`.

### `05-motion-lower-third/` — МОУШН-ПЛАШКА
Анимированная нижняя плашка «Ардак Аблай / Eurasian Trading Group»
с прозрачным фоном. `.webm` для CapCut, `.mov` для Premiere.

### `06-hero-video/` — ВИДЕО ДЛЯ ГЕРОЯ
Ambient-ролик для фона лендинга (тёмный фон, латунная спираль).
Если папки нет или она пустая — видео ещё генерируется или запустим
позже. Лендинг работает и без него (на анимированной спирали).

---

## ПОРЯДОК ДЕЙСТВИЙ

1. Прочитай `ПРОМПТ-ДЛЯ-ТЕРМИНАЛА.md`, собери свои данные (ссылки, домен)
2. Открой папку `01-landing-project/` в Claude Code
3. Вставь промпт, отвечай на вопросы терминала
4. Проверь результат, задеплой на Vercel
5. Реклама (`04-ads/`) запускается независимо — можно параллельно

---

## ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ

- Сборка падает → пришли мне (Клоду) текст ошибки, разберём
- Терминал нарушает стиль → покажи ему `03-brand/design-system.html`
- Видео не вставляется → проверь, что файлы в `public/video/`
  и раскомментирован блок `<video>` в `HeroBackdrop.tsx`

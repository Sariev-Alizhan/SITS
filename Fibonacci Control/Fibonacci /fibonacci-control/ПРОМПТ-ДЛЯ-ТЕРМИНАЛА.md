## Шаг 1. Запуск и проверка
```
npm install

```
Убедись, что сборка проходит без ошибок. Затем `npm run dev` и проверь,
что страница открывается на http://localhost:3000, включая мобильную
раскладку (проверь при ширине 390px).

## Шаг 3. Фото для героя (одна команда)
Герой сделан как в референсе: большое фото + 3 карточки-навигации справа.
Фото уже сгенерированы. Скачай их одной командой:

```
bash scripts/prepare-images.sh
```

Скрипт положит 4 картинки в `public/images/` (hero + 3 карточки).
URL уже прописаны в скрипте. Фото — тёмные, брендовые (латунная спираль,
приборы, переговорная). Пока файлов нет, лендинг работает на анимированной
спирали — но с фото выглядит как премиум-референс.

Если картинка не скачалась — URL продублированы в
`public/images/URL-картинок.txt`, там же инструкция взять свежую ссылку.

## Шаг 4. Видео-фон героя (по желанию)
Ролик уже сгенерирован. Прогони скрипт — он скачает видео и сделает
из него webm + mp4 + постер, положив всё в public/video/:

```
bash scripts/prepare-hero-video.sh "ВСТАВЬ_СЮДА_URL_ВИДЕО"
```

URL видео я (Алижан) дам отдельно (он в чате с Клодом, в блоке про видео).
Скрипту нужен ffmpeg — если нет: `brew install ffmpeg`.

После скрипта открой `src/components/HeroBackdrop.tsx` и поставь в первой
строке компонента `USE_VIDEO = true`. Проверь, что текст читается поверх
видео — скрипт уже слегка притемняет ролик, но если надо ещё темнее,
уменьши `opacity` у `.hero-video`.

## ЖЕЛЕЗНЫЕ ПРАВИЛА (не нарушай — это дизайн-система, не вкусовщина)
- **Латунь `--color-aurum` ≤ 5% площади**, только на действии (главная
  кнопка). Второе действие — всегда `.btn-ghost`. Латунь НИКОГДА не статус.
- **Отступы — только из `--spacing-*`** (ряд Фибоначчи × 4px). Никаких
  произвольных `margin: 17px`.
- **Кегль — только из `--text-*`** (тоже ряд Фибоначчи).
- **Шрифт Archivo — ТОЛЬКО логотип** (нет кириллицы). Весь текст, включая
  русские заголовки — `Onest`. Данные и метки — `Martian Mono`.
- **Голос:** без «упс», без эмодзи, без «взорвём продажи». Ошибки говорят,
  что случилось и что делать. Сверяйся с `../03-brand/design-system.html` —
  это эталон.
- **`prefers-reduced-motion` уважается везде** — не убирай проверки.

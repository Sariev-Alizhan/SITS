# ТЗ: экраны-страницы как у exoton (не скролл, а переходы)

## Что хочет клиент
Сейчас карточки в герое (Продукт / Принцип / Написать нам) ведут на якоря
(#product, #how, #contact) и СКРОЛЛЯТ вниз по одной длинной странице.

Нужно как у референса exoton.agency: клик на карточку → открывается
ОТДЕЛЬНАЯ полноэкранная СТРАНИЦА (/product, /how, /contact). Главная
становится ТОЛЬКО экраном-обложкой (герой + 3 карточки-навигации),
без длинного скролла вниз.

## Архитектура (Next.js App Router)

Преврати текущие секции в отдельные роуты:

```
src/app/
  page.tsx           → ТОЛЬКО герой-обложка (фото + 3 карточки справа)
                       УБРАТЬ секции problem/how/product/contact со скролла
  product/page.tsx    → страница «Продукт» (что была секцией #product)
  how/page.tsx        → страница «Принцип» (что была секцией #how + problem)
  contact/page.tsx    → страница «Написать нам» (форма-заявка + контакты)
  layout.tsx          → без изменений (шрифты, Lenis, метаданные)
```

## Карточки героя → ссылки на роуты
В компоненте карточек (HeroCards.tsx или где они) поменяй href:
```
{ img: '/images/card-product.jpg',   label: 'Продукт',      href: '/product' }
{ img: '/images/card-principle.jpg', label: 'Принцип',      href: '/how' }
{ img: '/images/card-contact.jpg',   label: 'Написать нам', href: '/contact' }
```
Используй next/link (<Link href="/product">) для мгновенных переходов
без перезагрузки — это и даёт ощущение «приложения», как у exoton.

## Layout внутренних страниц (важно — держать стиль exoton)
Каждая страница /product, /how, /contact — тот же split-экран, что и главная:
- Слева (61.8%): большое фото раздела (используй ту же card-*.jpg или
  hero.jpg) + крупный заголовок раздела + короткий подзаголовок
- Справа (38.2%): контент раздела (текст/форма/карточка-дашборд)
- Сверху: та же пилюля-навигация (логотип + меню + «Написать нам»)
- Кнопка «← Назад» или клик по логотипу → возврат на главную (/)
- Плавный переход (fade/slide) при навигации — можно Framer Motion
  или CSS view-transitions

На мобилке: фото сверху, контент снизу (как главная сейчас).

## Что перенести в какую страницу
- /product: секция «Продукт» (карточка сделки DL-2584, KPI, формула
  Фибоначчи). Можно расширить: список возможностей CRM.
- /how: секции «Проблема» (3 боли) + «Принцип» (3 шага, ряд Фибоначчи).
- /contact: форма-заявка (та, что ты уже сделал) + плавающие контакты
  (Telegram @zhanmate, Instagram fibonacci.control, WhatsApp 77774961358).

## Дизайн-правила (не нарушать)
- Латунь (--color-aurum) ≤5%, только на главном действии
- Отступы только из --spacing-* (ряд Фибоначчи)
- Archivo только логотип, текст — Onest, данные — Martian Mono
- Сетка 61.8/38.2 на всех страницах
- prefers-reduced-motion уважать

## Проверка после сборки
1. На главной остался ТОЛЬКО герой-обложка (нет длинного скролла вниз)
2. Клик «Продукт» → URL меняется на /product, открывается страница
3. Клик «Принцип» → /how, «Написать нам» → /contact
4. Клик по логотипу → возврат на /
5. Переходы плавные, без белой вспышки
6. На мобилке всё в один столбец
7. npm run build проходит, задеплоить

## Не сломать
- Форму-заявку и /api/lead (перенести в /contact как есть)
- Видео/фото героя (остаётся на главной)
- Реальные ссылки контактов

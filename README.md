# SITS — пакет файлов сайта

Всё для продолжения работы над сайтом Sariyev IT Solutions в терминале и Claude Design.

## Быстрый старт

1. Открой `sits-website.html` в браузере — это готовый рабочий сайт (день/ночь тема, услуги, портфолио-описания, форма).
2. Для локального запуска со всеми иконками: из этой папки запусти
   ```bash
   python3 -m http.server 8000
   ```
   и открой `http://localhost:8000/sits-website.html`.

## Что внутри

- **sits-website.html** — сайт одним файлом (HTML+CSS+JS, без зависимостей кроме Google Fonts).
- **brand/** — логотипы (светлый, тёмный, прозрачный), favicon, иконка для iOS.
- **portfolio/** — скриншоты 9 проектов: `*_*.png` (hero, retina 2880×1800) и `*_full.png` (вся страница).
- **docs/design-brief.md** — дизайн-направление на основе research трендов 2026 + брендбук + структура.
- **docs/content.json** — все данные бренда, услуг и портфолио в структурированном виде (удобно скармливать Claude Design / генератору секций).

# Настройка заявок: Telegram + CRM

Заявки с формы будут (1) мгновенно падать тебе в Telegram и (2) сохраняться в CRM на странице `/admin`. Всё разворачивается на Vercel (как твои другие сайты).

## Структура для деплоя

В корне проекта на Vercel должно лежать:

```
index.html          ← твой сайт (переименуй sits-website.html в index.html)
admin.html          ← страница CRM
brand/              ← логотипы и favicon (нужны сайту и CRM)
api/
  lead.js           ← приём заявки (Telegram + сохранение)
  leads.js          ← выдача заявок для CRM
package.json        ← зависимость @vercel/kv
```

Файлы `api/`, `admin.html`, `package.json` лежат в папке `crm/` этого пакета — перенеси их в корень проекта.

## Шаг 1. Telegram-бот (мгновенные уведомления)

1. В Telegram открой **@BotFather** → команда `/newbot` → задай имя и username. Он выдаст **токен** вида `12345:ABC...` — это `TELEGRAM_BOT_TOKEN`.
2. Напиши своему новому боту любое сообщение (например «привет») — иначе он не сможет тебе писать.
3. Узнай свой **chat_id**: напиши боту **@userinfobot** — он пришлёт твой ID (число). Это `TELEGRAM_CHAT_ID`.

## Шаг 2. Хранилище для CRM (Vercel KV)

1. В дашборде Vercel → проект → вкладка **Storage** → **Create Database** → **KV** (Upstash Redis). Бесплатного тарифа хватает.
2. Привяжи базу к проекту кнопкой **Connect** — Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.

## Шаг 3. Переменные окружения

Vercel → проект → **Settings → Environment Variables**. Добавь:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | твой chat_id от @userinfobot |
| `ADMIN_PASSWORD` | любой пароль для входа в CRM (придумай сам) |

(`KV_REST_API_URL` и `KV_REST_API_TOKEN` Vercel добавил автоматически на шаге 2.)

После добавления переменных нажми **Redeploy**, чтобы они применились.

## Шаг 4. Деплой

Из корня проекта в терминале:

```bash
npm install        # подтянет @vercel/kv
npx vercel         # первый деплой (или git push, если проект связан с GitHub)
```

## Готово

- Заявка с сайта → тебе в Telegram приходит сообщение и заявка сохраняется.
- CRM открывается по адресу **твой-домен/admin** → вводишь `ADMIN_PASSWORD` → видишь таблицу заявок с поиском.

## Заметки

- Обе интеграции независимы: если не настроишь Telegram — заявки всё равно сохранятся в CRM, и наоборот. Можно начать только с Telegram, а KV добавить позже.
- Защита CRM — простым паролем. Для команды позже можно усилить (нормальная авторизация, роли) — скажи, добавлю.
- Не коммить токены в код — они только в Environment Variables.
